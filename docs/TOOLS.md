# Tools reference

Generated from `tools/list` (PrestaPro MCP 1.1.0). Every tool also accepts the injected arguments
`id_shop` / `lang` where noted, and write tools accept `dry_run`. Tools a key may not call are not listed to it.

## Shop context (`shop_*`)

| tool | type | arguments | description |
|---|---|---|---|
| `shop_config_get` | read | `keys`, `prefix` · +id_shop/lang | Reads PrestaShop Configuration values for the shop (and language for multilang keys), by exact keys or by prefix (e.g. "PS_STOCK", or a module prefix like "PPSLIDER_"). Secret-looking values (passwords, API keys, tokens) are masked. Read-only. |
| `shop_context_get` | read | +id_shop | Start here. Returns PrestaShop/PHP versions, whether multistore is active, every shop (id, group, domains, default language/currency), languages and currencies per shop, and the key storefront settings (catalog mode, stock management, out-of-stock ordering, guest checkout, minimum purchase, tax display, maintenance). Use the ids it returns for id_shop and lang arguments. |
| `shop_log_list` | read | `severity_min`, `search`, `object_type`, `object_id`, `date_from`, `limit`, `offset` | Reads the PrestaShop log (Advanced Parameters > Logs): errors, warnings and info messages from core and modules, newest first. Filter by severity (1 info, 2 warning, 3 error, 4 major), text, object type/id (e.g. object_type "Cart" + object_id shows why a cart/payment failed) and date. Use it when debugging failures. |

| `catalog_specific_price_delete` | **destructive** | `id_specific_price`* · +id_shop | Deletes one specific price by id (catalog_specific_price_list). | `catalog_stock_set` | **write** | `id_product`*, `id_product_attribute`, `quantity`, `delta`, `out_of_stock` · +id_shop | Sets the available quantity of a product or of one combination in the shop (shared stock groups are handled by PrestaShop), either as an absolute quantity or as a delta (+5 / -2), and/or its out-of-stock behaviour (0 deny orders, 1 allow orders, 2 use the shop default; applies to the whole product). `*` = required.
